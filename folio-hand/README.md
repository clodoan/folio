# Folio hand - studio caps v1

Architectural print. Glyphs are strokes. Round 0.45mm felt-tip.

## How letters are drawn
Each glyph in studio-caps-v1.json is ordered cubic Bezier strokes (y-up, unslanted, cap = 10 units).
Renderer strokes a 0.45mm round felt-tip along the centerline. No nib rectangle.
No joins. No Hershey. No Palatino.

Locked: A-Z only. Cap 4.35mm. Tracking 0.11-0.13x. Word space 0.40x. Leading 2.42x. Slant 1.15 deg (not italic). Ink #2A5F9E on paper #F3EBDC.
Constructed print: E stem+3 bars; M/N/W zigzags; bowls overshoot; stems bow.

## Seed
hash(ISO-date + studio-caps-v1). Baseline wander; per-letter +/-0.15mm, rotation +/-1.5deg, size 0.96-1.04.
Signature: 1.4x CA initials off-grid. Pencil date top-right. Last cluster more careless.
