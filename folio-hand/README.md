# Folio hand

Cursive strokes. Round 0.45mm felt-tip. Ink #2A5F9E on paper #F3EBDC.

Live hand id is `recipes-cursive-v1`. Each glyph is a few key points with join tags. The writer concatenates strokes, Chaikin-smooths them, then fills a thin ribbon. Seed is `hash(ISO-date + recipes-cursive-v1)`. Cap 6.44mm. Slant 11 degrees. Lowercase is in the alphabet.

Not a system font. Not Hershey. Not Palatino.
